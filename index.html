The Vel'nar Script

How the Writing System Works
WHAT EACH GLYPH REPRESENTS

Each glyph represents one root — not one sound, not one letter. The script is logographic: you read meaning directly, not phonetics. A fluent reader does not decode sounds and reconstruct meaning. They read the root and receive its meaning whole.

DIRECTIONALITY

Written vertically, top to bottom. Columns run right to left. Sovereignty descends — it does not spread horizontally. The first statement of a text occupies the rightmost column and runs downward. The next statement begins a new column to the left.

COMPOUND WORDS

The governing (lead) root is written above. The modifying root is written below it, slightly indented to the right. VEL NAR is written with VEL glyph on top, NAR glyph below and slightly right. The visual hierarchy mirrors the grammatical hierarchy — the governing root is literally elevated.

PREFIXES & SUFFIXES

Prefixes (an-, za-, dor-) are written as small stroke marks to the LEFT of the main root glyph, touching the glyph's upper-left edge. Suffixes (-kal, -eth, -en, -sol) are written as small stroke marks to the RIGHT of the main root glyph, at the lower-right edge. The marks are smaller than the root — they modify without dominating.

PUNCTUATION & SILENCE

A single horizontal line drawn between two glyphs marks a breath pause — a silence with syntactic meaning. A double horizontal line marks a phrase boundary (end of a complete statement). No other punctuation exists. The silence carries the connective meaning that other languages assign to conjunctions.

PRACTICE SEQUENCE
  1. Learn each root glyph alone. Trace it 20 times while speaking the root name aloud.
  2. Practice compound stacking: write the governing root, pause, write the modifying root below and right.
  3. Practice prefix marks: write the root, add the an- mark to its left. Write it again with za-.
  4. Practice suffix marks: write the root, add the -kal mark to its right.
  5. Practice full phrases vertically: AN IM-VEL written top to bottom as three stacked elements.
  6. Practice silence lines between phrases.
THE STANDARD

Vel'nar script is written slowly and deliberately. Speed is not a mark of fluency — precision is. A glyph written in 30 seconds with full attention is correct. The same glyph written in 3 seconds is probably not. Speak the root name as you trace the glyph. The voice and hand teach each other.
